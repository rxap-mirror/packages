# Installation

**Add the package to your workspace:**
```bash
yarn add @rxap/nest-typeorm
```
**Install peer dependencies:**
```bash
yarn add @nestjs/common @nestjs/config @nestjs/typeorm @rxap/nest-utilities joi typeorm 
```
