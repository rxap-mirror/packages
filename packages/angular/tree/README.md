This package provides a tree component and data source for Angular applications. It includes features such as searching, filtering, and displaying hierarchical data. The package also offers directives for customizing the content of tree nodes.

# Installation

**Add the package to your workspace:**
```bash
yarn add @rxap/tree
```
**Install peer dependencies:**
```bash
yarn add @angular/cdk@^19.1.1 @angular/common@^19.1.3 @angular/core@^19.1.3 @angular/material@^19.1.1 @rxap/contenteditable@^19.0.2-dev.1 @rxap/data-source@^19.0.2-dev.2 @rxap/data-structure-tree@^1.1.13-dev.1 @rxap/forms@^19.0.2-dev.1 @rxap/material-directives@^19.0.2-dev.2 @rxap/pattern@^1.1.12-dev.1 @rxap/rxjs@^1.1.13-dev.1 @rxap/utilities@^16.4.3-dev.1 rxjs@^7.8.1 
```
**Execute the init generator:**
```bash
yarn nx g @rxap/tree:init
```
