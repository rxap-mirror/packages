# Installation

**Add the package to your workspace:**
```bash
npm install @rxap/n8n-nodes-tar
```
With pnpm or yarn use `pnpm add` or `yarn add` instead of `npm install`.

**Install peer dependencies:**
```bash
npm install n8n-workflow 
```
