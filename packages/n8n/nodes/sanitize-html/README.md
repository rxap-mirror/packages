# Installation

**Add the package to your workspace:**
```bash
yarn add @rxap/n8n-nodes-sanitize-html
```
**Install peer dependencies:**
```bash
yarn add n8n-workflow@^1.48.0 
```
**Execute the init generator:**
```bash
yarn nx g @rxap/n8n-nodes-sanitize-html:init
```
